# Calculation of the Electric Field of a Helix

</br>
<h1>Project Description</h1>
This project calculates the electric field at the point (0,0,0) from a helix using Mathematica. The calculation is performed through numerical integration of the charge distribution along the helix.

<h1>Requirements</h1>
<li><a href='https://www.wolfram.com/mathematica/'>Wolfram Mathematica</a></li>
<li>Basic knowledge of electromagnetism and numerical integration</li>


<h1>Project Structure</h1>
<b>main.nb</b>: Main file containing the calculation and visualization of the electric field


<h1>Usage</h1>
1-Open the file main.nb in Mathematica.</br>
2-Execute the notebook step by step.</br>
3-Analyze the computed results and visualizations.
